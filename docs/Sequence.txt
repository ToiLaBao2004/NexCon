Sequence:
1. Đăng ký tài khoản và xác thực OTP
@startuml
autonumber

actor "Người dùng" as User

participant "FE\nSignUpPage / SignupForm" as SignUpFE
participant "FE\nOtpPage / OTPForm" as OtpFE

participant "BE\nauthController" as AuthController
participant "BE\notpController" as OtpController

database "Database\nMongoDB\n(users, otps)" as DB
participant "EmailService\nsendEmail.js / Brevo API" as EmailService

User -> SignUpFE: Nhập thông tin đăng ký
SignUpFE -> AuthController: POST /api/auth/verify-valid-fields-signup
AuthController -> DB: Kiểm tra email đã tồn tại
DB --> AuthController: Email chưa tồn tại

AuthController --> SignUpFE: Thông tin đăng ký hợp lệ

SignUpFE -> OtpController: POST /api/otp/otp-create-user
OtpController -> DB: Tạo và lưu OTP đăng ký
DB --> OtpController: OTP đã được lưu

OtpController -> EmailService: Gửi email chứa OTP
EmailService --> OtpController: Gửi email thành công

OtpController --> SignUpFE: Trả kết quả gửi OTP
SignUpFE --> OtpFE: navigate("/otp", { signupData })

User -> OtpFE: Nhập mã OTP
OtpFE -> AuthController: POST /api/auth/signup
AuthController -> DB: Kiểm tra email và OTP đăng ký
DB --> AuthController: Kết quả kiểm tra

alt Email đã tồn tại hoặc OTP sai/hết hạn
    AuthController --> OtpFE: Trả lỗi đăng ký/xác thực OTP
    OtpFE --> User: Hiển thị lỗi
else OTP hợp lệ
    AuthController -> DB: Tạo tài khoản người dùng
    DB --> AuthController: Tài khoản đã được tạo

    AuthController --> OtpFE: Đăng ký thành công
    OtpFE --> User: Chuyển sang màn hình đăng nhập
end

@enduml

2. Đăng Nhập Bằng Email và Google
@startuml
autonumber

actor "Người dùng" as User

participant "FE\nSignInPage / SigninForm / OAuthSuccess" as FE

participant "BE\nauthController" as AuthController
participant "BE\nuserController" as UserController

database "Database\nMongoDB\n(users, sessions)" as DB
participant "Google OAuth\nProvider" as Google
participant "Cloudinary\nMedia Storage" as Cloudinary

== Luồng 1: Đăng nhập bằng Email ==

User -> FE: Nhập email và mật khẩu
FE -> AuthController: POST /api/auth/signin
AuthController -> DB: Xác thực tài khoản và tạo session
DB --> AuthController: Kết quả xác thực

alt Sai thông tin đăng nhập hoặc tài khoản bị khóa
    AuthController --> FE: Trả lỗi đăng nhập
    FE --> User: Hiển thị lỗi
else Đăng nhập thành công
    AuthController --> FE: Trả accessToken, user và refreshToken cookie

    FE -> UserController: GET /api/users/me
    UserController -> DB: Lấy thông tin người dùng hiện tại
    DB --> UserController: Thông tin người dùng
    UserController --> FE: Trả dữ liệu người dùng

    FE --> User: Chuyển vào ứng dụng
end

== Luồng 2: Đăng nhập bằng Google ==

User -> FE: Chọn đăng nhập bằng Google
FE -> AuthController: GET /api/auth/google
AuthController -> Google: Chuyển hướng đến Google OAuth

User -> Google: Chọn tài khoản Google
Google -> AuthController: GET /api/auth/google/callback

AuthController -> DB: Tìm hoặc tạo tài khoản Google
DB --> AuthController: Thông tin tài khoản

AuthController -> Cloudinary: Lưu avatar Google nếu cần
Cloudinary --> AuthController: URL avatar

AuthController -> DB: Lưu/cập nhật user và session
DB --> AuthController: Session đã được lưu

AuthController --> FE: Redirect /oauth-success

FE -> AuthController: GET /api/auth/google/success
AuthController -> DB: Kiểm tra session từ refreshToken cookie
DB --> AuthController: Session hợp lệ
AuthController --> FE: Trả accessToken

FE -> UserController: GET /api/users/me
UserController -> DB: Lấy thông tin người dùng hiện tại
DB --> UserController: Thông tin người dùng
UserController --> FE: Trả dữ liệu người dùng

FE --> User: Chuyển vào ứng dụng

@enduml

AuthUserController -> DB: Kiểm tra mật khẩu hiện tại
DB --> AuthUserController: Kết quả kiểm tra

    AuthUserController --> SettingsFE: Trả lỗi đổi mật khẩu
    SettingsFE --> User: Hiển thị lỗi
else Mật khẩu hiện tại hợp lệ
    AuthUserController -> DB: Cập nhật mật khẩu mới
    DB --> AuthUserController: Mật khẩu đã được cập nhật

    AuthUserController --> SettingsFE: Trả kết quả đổi mật khẩu thành công
    SettingsFE --> User: Hiển thị thông báo thành công

participant "Socket\nSocket.IO" as Socket

== Xem gợi ý và lời mời kết bạn ==

User -> PeopleFE: Mở trang kết bạn
PeopleFE -> FriendController: GET /api/friends/suggestions
FriendController -> DB: Tính toán gợi ý kết bạn
DB --> FriendController: Danh sách gợi ý
FriendController --> PeopleFE: Trả suggestions

PeopleFE -> FriendController: GET /api/friends/requests
FriendController -> DB: Lấy lời mời kết bạn đến
DB --> FriendController: Danh sách lời mời đến
FriendController --> PeopleFE: Trả friendRequests

PeopleFE -> FriendController: GET /api/friends/requests-sended
FriendController -> DB: Lấy lời mời đã gửi
DB --> FriendController: Danh sách lời mời đã gửi
FriendController --> PeopleFE: Trả friendRequests

== Gửi lời mời kết bạn ==

User -> PeopleFE: Tìm người dùng hoặc chọn gợi ý kết bạn
PeopleFE -> FriendController: POST /api/friends/send-request
FriendController -> DB: Kiểm tra người nhận và quan hệ hiện tại

alt Không thể gửi lời mời
    DB --> FriendController: Người dùng không tồn tại / đã là bạn / bị chặn
    FriendController --> PeopleFE: Trả lỗi gửi lời mời
    PeopleFE --> User: Hiển thị lỗi
else Gửi lời mời thành công
    FriendController -> DB: Lưu friend request
    DB --> FriendController: Friend request đã được lưu

    FriendController -> Socket: Gửi sự kiện new-friend-request
    Socket --> FriendController: Đã phát sự kiện

    FriendController --> PeopleFE: Trả kết quả gửi lời mời thành công
    PeopleFE --> User: Cập nhật danh sách lời mời đã gửi
end

== Chấp nhận hoặc từ chối lời mời ==

User -> PeopleFE: Chấp nhận lời mời kết bạn
PeopleFE -> FriendController: POST /api/friends/accept-request/{requestId}
FriendController -> DB: Tạo quan hệ bạn bè và cập nhật lời mời
DB --> FriendController: Bạn bè đã được tạo

FriendController -> Socket: Gửi sự kiện friend-request-accepted
Socket --> FriendController: Đã phát sự kiện

FriendController --> PeopleFE: Trả kết quả chấp nhận thành công
PeopleFE --> User: Cập nhật danh sách bạn bè

User -> PeopleFE: Từ chối lời mời
PeopleFE -> FriendController: POST /api/friends/reject-request/{requestId}
FriendController -> DB: Cập nhật trạng thái lời mời
DB --> FriendController: Lời mời đã được từ chối

FriendController -> Socket: Gửi sự kiện friend-request-rejected
Socket --> FriendController: Đã phát sự kiện

FriendController --> PeopleFE: Trả kết quả từ chối thành công
PeopleFE --> User: Cập nhật danh sách lời mời

User -> PeopleFE: Hủy lời mời đã gửi
PeopleFE -> FriendController: DELETE /api/friends/cancel-request/{requestId}
FriendController -> DB: Xóa lời mời đã gửi
DB --> FriendController: Lời mời đã được xóa

FriendController -> Socket: Gửi sự kiện friend-request-cancelled
Socket --> FriendController: Đã phát sự kiện

FriendController --> PeopleFE: Trả kết quả hủy lời mời thành công
PeopleFE --> User: Cập nhật danh sách lời mời đã gửi

DB --> ConversationController: Đã cập nhật
ConversationController --> ChatFE: Trả trạng thái ghim mới

ConversationController -> Socket: Phát sự kiện conversation-cleared
Socket --> ConversationController: Đã phát sự kiện
ConversationController --> ChatFE: Trả kết quả xóa hội thoại

alt Hội thoại không hợp lệ hoặc không có quyền

    ChatFE --> User: Hiển thị thông báo lỗi

@startuml
title Sequence - Gửi báo cáo vi phạm

actor "Người dùng" as User

participant "BE\nreportController" as BE
database "Database\nMongoDB\nUser / Message / Conversation / Report" as DB

== Mở form báo cáo ==

User -> FE: Chọn "Báo cáo"
FE -> User: Hiển thị ReportDialog\nchọn lý do và nhập mô tả

User -> FE: Bấm "Gửi báo cáo"

alt Báo cáo tin nhắn
    FE -> BE: POST /api/reports/messages/{messageId}

    BE -> DB: Lấy Message được báo cáo
    DB --> BE: Message

    BE -> DB: Kiểm tra Conversation\nngười báo cáo có quyền xem tin nhắn
    DB --> BE: Conversation hợp lệ

    BE -> DB: Lấy User gửi tin nhắn
    DB --> BE: Target user

    BE -> DB: Kiểm tra report đang pending/reviewing
    DB --> BE: Chưa có report trùng

    BE -> DB: Tạo Report\nkèm reporterSnapshot,\ntargetUserSnapshot,\nmessageSnapshot
    DB --> BE: Report đã tạo

    BE --> FE: 201 Created\n{ message, report }

else Báo cáo người dùng
    FE -> BE: POST /api/reports/users/{userId}

    BE -> DB: Lấy User bị báo cáo
    DB --> BE: Target user

    BE -> DB: Kiểm tra Conversation nếu có conversationId
    DB --> BE: Conversation hợp lệ

    BE -> DB: Kiểm tra report đang pending/reviewing
    DB --> BE: Chưa có report trùng

    BE -> DB: Tạo Report\nkèm reporterSnapshot,\ntargetUserSnapshot
    DB --> BE: Report đã tạo

    BE --> FE: 201 Created\n{ message, report }
end

FE -> User: Hiển thị thông báo\n"Đã gửi báo cáo"

== Lỗi quan trọng ==

alt Đã có báo cáo đang chờ xử lý
    BE --> FE: 409 Conflict\n{ message }
    FE -> User: Hiển thị lỗi\n"Bạn đã báo cáo nội dung này"
end

@enduml

16. Quản lý báo cáo vi phạm
@startuml
skinparam defaultFontSize 20

actor "Quản trị viên" as Admin

participant "FE\nAdminReportsPage\nAdminEvidencePreview / AdminUserDrawer" as FE
participant "BE\nadminController" as BE
database "Database\nMongoDB\nReport / User / Message / Notification" as DB
participant "AI Moderation\nGemini / OpenAI / AssemblyAI" as AI
participant "Socket.IO Cluster\nRedis Adapter" as Socket
participant "NotificationService" as Notify

== Xem danh sách báo cáo ==

Admin -> FE: Mở trang quản lý báo cáo
FE -> BE: GET /api/admin/reports?targetType={message|user}&status={status}&limit=100

BE -> DB: Lấy danh sách Report\nkèm evidence nếu là message report
DB --> BE: reports + messageEvidence

BE --> FE: 200 OK { reports, pagination }
FE -> Admin: Hiển thị danh sách báo cáo

== Đánh dấu đang xem xét ==

Admin -> FE: Chọn báo cáo\nvà bấm "Đang xem xét"
FE -> BE: PATCH /api/admin/reports/{reportId}/reviewing

BE -> DB: Cập nhật Report\nstatus = reviewing,\nreviewedBy, reviewedAt
DB --> BE: Report đã cập nhật

BE --> FE: 200 OK { report }
FE -> Admin: Cập nhật trạng thái báo cáo

== AI lọc báo cáo tin nhắn ==

Admin -> FE: Bấm "AI lọc hàng loạt"
FE -> BE: POST /api/admin/reports/messages/ai-review

BE -> DB: Lấy các Report tin nhắn\nstatus pending/reviewing
DB --> BE: Reports + target messages

BE -> AI: Kiểm duyệt lại nội dung tin nhắn
AI --> BE: Kết quả moderation

alt AI xác nhận vi phạm đủ tự tin
    BE -> DB: Resolve Report = violation\nvà lưu aiModeration

    BE -> DB: Cập nhật Message\nreportStatus = true
    DB --> BE: Message đã bị đánh dấu vi phạm

    BE -> DB: Ghi nhận violation cho target user\nvà khóa tài khoản nếu vượt ngưỡng
    DB --> BE: Violation summary

    BE -> Socket: emit "message-moderated"
    Socket --> FE: Cập nhật tin nhắn bị ẩn / vi phạm

    BE -> Notify: Tạo thông báo kết quả report\ncho reporter và target user
    Notify -> DB: Lưu Notification
else AI chưa đủ chắc chắn
    BE --> FE: Trả kết quả cần admin xem tiếp
end

BE --> FE: 200 OK { scanned, resolved, needsReview, results }
FE -> Admin: Hiển thị kết quả AI review

== Admin kết luận báo cáo ==

Admin -> FE: Chọn "Xác nhận vi phạm"\nhoặc "Không vi phạm"
FE -> BE: PATCH /api/admin/reports/{reportId}/resolve

alt Quyết định: violation
    BE -> DB: Cập nhật Report\nstatus = resolved,\nresolution.decision = violation
    DB --> BE: Report đã cập nhật

    BE -> DB: Nếu là message report:\ncập nhật Message.reportStatus = true
    DB --> BE: Message đã cập nhật

    BE -> DB: Ghi nhận violation cho target user\nvà khóa tài khoản nếu vượt ngưỡng
    DB --> BE: Violation summary

    BE -> Socket: emit "message-moderated"
    Socket --> FE: Realtime cập nhật tin nhắn vi phạm

    BE -> Notify: Gửi thông báo cho người báo cáo\nvà người bị báo cáo
    Notify -> DB: Lưu Notification

    BE --> FE: 200 OK { report }

else Quyết định: no_violation
    BE -> DB: Cập nhật Report\nstatus = dismissed,\nresolution.decision = no_violation
    DB --> BE: Report đã cập nhật

    BE -> Notify: Gửi thông báo kết quả\ncho người báo cáo
    Notify -> DB: Lưu Notification

    BE --> FE: 200 OK { report }
end

FE -> Admin: Làm mới danh sách báo cáo

@enduml
